# networking-reports
This repository contains my networking practical reports and hands-on lab work related to computer networks. The reports cover topics such as LAN and WAN networks, IP addressing, MAC addresses, subnetting, VLSM, DNS, ARP, DHCP, SSH, Telnet, routing, network topologies, and network configuration. Practical work is performed using tools such as Cisco Packet Tracer, Wireshark, Windows Command Prompt, and Kali Linux. The reports include practical configurations, network diagrams, commands, connectivity testing, screenshots, and observations. This repository documents my practical networking work and will be updated with new reports and lab exercises over time.
